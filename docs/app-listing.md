## Long Description

Levoit TempSense 36 Pro Remote IR is an unofficial Android infrared remote control app for the Levoit TempSense 36 Pro tower fan. It sends NEC infrared commands through Android's native `ConsumerIrManager` API and is intended for phones with integrated IR blasters, such as compatible Xiaomi and Redmi models.

The app includes power, swing, timer, fan speed, sleep mode, mode, and sound controls. It also includes local sync controls so the app display can be manually aligned with the real tower state when a command was sent without pointing at the fan.

This project is useful for anyone looking for a replacement remote app, Levoit IR codes, Xiaomi IR remote support, Redmi IR blaster support, or an Android NEC protocol fan remote APK.
